# NOA: Network Operations Assistant

A local AI assistant that works like a small network operations center (NOC). NOA helps troubleshoot network problems and monitor network health, the day-to-day work a NOC team does. It runs locally on Linux and takes voice commands through offline speech recognition.

Final-year B.Tech. project by **Junior Nemoh Asong Egbe**, Catholic University Institute of Buea. Defended June 2026.

**Built with:** Python · Linux · Vosk (offline speech recognition)
